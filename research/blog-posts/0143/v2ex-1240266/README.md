# 户外相机海外平台：需求分析与概要设计

版本：1.0｜资料截点：2026-09-08｜状态：架构方案定稿，待实测与业务条件核准后实施。

## 决定

采用**按租户划分归属区、区内单写、跨区访问原归属区、媒体按需分发**的架构。海外一期采用 AWS 的托管数据库和对象存储，复用现有 Go 与 Kubernetes 工程能力。先建设一个可重复部署的区域单元，按市场上线顺序扩展到美国、法国、新加坡；非洲先做真实运营商测试，再决定接入点或完整区域。国内系统保持独立。

同一个账号出国后继续使用原有数据，不重新注册。实现这一点靠稳定的身份和归属区路由，不靠把用户表、业务库和录像复制到所有国家。租户归属区不会随着 GeoDNS、手机 IP 或旅行自动改变。

这是针对原帖约束作出的设计决定，不是对既有系统的审计报告。原帖没有流量样本、成本账单、完整设备协议和客户合同。本文补充的容量、服务目标和交付顺序均有明确标记；未完成的验证不会写成已通过。
