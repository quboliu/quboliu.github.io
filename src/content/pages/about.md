This is quboliu's minimal publishing space, built with [Astro](https://astro.build/), [AstroPaper](https://github.com/satnaing/astro-paper), and GitHub Pages.

## Features

- Markdown and MDX
- Local images and responsive output
- YouTube, Bilibili, and hosted video
- Full-text search, tags, archives, and RSS
- Light and dark mode
- Comments powered by GitHub Discussions

## Source

The source is available on [GitHub](https://github.com/quboliu/quboliu.github.io).
