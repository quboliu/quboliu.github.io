我是蘧伯流，一名喜欢把想法做成工具的开发者。

目前公开维护的项目主要围绕 Markdown 编辑、AI 工具与代码学习：

- [flintmark](https://github.com/quboliu/flintmark)：在 VS Code 中提供 Obsidian 风格的 Markdown 实时预览。
- [multi-prompt-dispatcher](https://github.com/quboliu/multi-prompt-dispatcher)：把一个提示词分发到多个 AI Web 应用。
- [codejym](https://github.com/quboliu/codejym)：面向源码刻意练习与记忆的代码训练工作室。

## 为什么写

项目展示“做了什么”，文章更适合保存“为什么这么做”。这里会记录实现过程、设计取舍、踩过的坑，以及一些尚未变成代码的思考。

我希望这些内容首先对未来的自己有用；如果也能帮到正在解决相似问题的人，就更好了。

## 这个博客

博客内容以 Markdown 和 MDX 保存在 GitHub，自动构建为静态页面。它支持本地图片、代码高亮、全文搜索、RSS，以及 YouTube、哔哩哔哩和外部视频文件。
