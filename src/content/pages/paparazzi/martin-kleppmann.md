### 作者情报：Martin Kleppmann

- **公开身份：** Martin Kleppmann 博士；[个人网站首页](https://martin.kleppmann.com/)自述为剑桥大学副教授，研究方向包括 local-first collaboration software 与分布式系统安全。
- **教学与研究：** 主页列出 Concurrent and Distributed Systems、Cryptography and Protocol Engineering 两门课程，并介绍其参与 [Automerge](https://automerge.org/) 开源项目。
- **职业轨迹：** 个人站点的 [About/Contact 页面](https://martin.kleppmann.com/contact.html)记录了剑桥大学（2015–2022）、慕尼黑工业大学系统研究组（2022–2023）等经历；更早曾创办 Go Test It，并联合创办 Rapportive，后者于 2012 年被 LinkedIn 收购。
- **写作与出版：** [Designing Data-Intensive Applications](https://dataintensive.net/) 第二版由 Martin Kleppmann 与 Chris Riccomini 合著，个人主页标注为 2026 年出版。
- **GitHub：** [ept](https://github.com/ept) 的公开资料显示姓名为 Martin Kleppmann，个人网站指向本博客，所在地为 Cambridge, UK；抓取时有 99 个 public repositories、6,654 个 followers。[GitHub 用户 API 快照](https://api.github.com/users/ept)
- **博客源码：** [ept/blog](https://github.com/ept/blog) 是个人博客源码仓库，仓库描述为使用 Markdown、Jekyll 和 Heroku 的个人博客源码；这说明博客内容有公开源代码入口，但不等于 GitHub Pages 托管。
- **代表性公开项目：** [Automerge](https://github.com/automerge/automerge)、[Hermitage 事务隔离测试套件](https://github.com/ept/hermitage)、[DDIA references](https://github.com/ept/ddia-references)、[CRDT website](https://github.com/ept/crdt-website)。
