这里开始写正文。

图片与文章放在同一目录：

```md
![图片说明](./image.png)
```

## 嵌入 YouTube

```mdx
<VideoEmbed
  provider="youtube"
  id="替换为视频 ID"
  title="视频标题"
/>
```

## 嵌入哔哩哔哩

```mdx
<VideoEmbed
  provider="bilibili"
  id="替换为 BV 号"
  title="视频标题"
  page={1}
/>
```

## 播放外部 MP4

```mdx
<HostedVideo
  src="https://media.example.com/video.mp4"
  poster="/images/video-cover.webp"
  title="视频标题"
  captions="https://media.example.com/video.zh.vtt"
/>
```
