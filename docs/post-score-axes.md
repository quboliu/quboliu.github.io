# Posts 连续轴的编辑规则

状态：布局 A 已实现。152 篇已发布文章都有阅读价值分数和逐篇理由，数据见 `src/data/postValueAssessments.ts`。LLM 记录见 `src/data/postLlmAssessments.ts`。

## 已确定的规则

- Posts 保留时间线、领域、标签，并增加「阅读价值」和「LLM 含量」两个并列视图。两个轴只收录本站原创文章；转载、翻译、论文和官方文档不进入样本集。
- 两个新视图都采用 0–100 的连续纵轴，每篇文章有对应位置。默认高价值在前；两个视图都可反转排序。相同数值按发布日期由近到远排列。
- 阅读价值使用固定评估尺度。新文章加入不改变旧文章的分数。公开显示一个总分和一段理由；质量与价值高度都进入判断，不公开额外的离散档位。分数是编辑评价，80 分不表示 40 分的两倍价值。
- LLM 含量轴表示「本站新增正文」中由 LLM 生成或改写的文字比例。第三方原文不进分母，其来源和创作方式另行说明。文章页同时列出 LLM 参与的制作环节。
- LLM 百分比可以是估计点，并附不确定区间及判断依据。完全没有制作线索时，用空心占位点和 0–100% 的全范围表示；占位点的绘图位置不作为百分比公布。
- 左轴支持点选文章、拖动数值范围；右侧列表同步筛选和排序。LLM 数值范围缩小时，「无依据」文章从数值结果中排除，并可从单独入口查看。
- 正式布局采用 A「左侧总览轴＋右侧排序列表」。

## 建议的显示和数据规则

| 字段 | 含义 |
| --- | --- |
| `value.score` | 0–100 的固定尺度编辑评价 |
| `value.reason` | 解释质量、洞见和适用价值的一段文字 |
| `value.reviewedAt` | 最近一次评估日期 |
| `llm.estimate` | 有线索时的本站新增文字生成比例估计；无依据时为空 |
| `llm.low`, `llm.high` | 估计区间；无依据时为 0 和 100 |
| `llm.roles` | 构思、资料检索、翻译、起草、改写、润色、核查等实际参与环节，可多选 |
| `llm.scope` | 分母包含的本站文字，例如原创正文、中文译文和译注 |
| `llm.basis` | 估计依据和来源说明；无依据时明确说明 |

比例只针对自然语言正文。转载的原文、引用材料、代码和图示不计入分母；若 LLM 参与了代码或图示制作，可在参与环节和说明里记录。用稿件与制作记录估计保留在最终版本中的 LLM 文字，不从文风或文章主题推断来源。

纵轴上的点保持准确的纵向数值位置。分数相同或十分接近时，可在水平方向错开；大量重合的无依据点先显示空心聚合标记，点开后在列表中逐篇查看。只有当前选中的文章显示完整不确定区间，以免 152 条区间互相遮挡。

## 维护规则

1. 新文章发布前逐篇写入阅读价值分数与理由；缺项会使轴页面构建失败。已有分数仅在重新读过文章、发现错误或内容有实质变更后调整，不因新文章加入而重排。
2. 分数不能从字数、`featured`、标签或 `contentType` 自动推导。原作价值和本站整理质量都要判断；转载身份本身不加减分。
3. LLM 估计只依据可核查的制作记录、文章明示来源或本次制作会话。发现新证据后再缩小范围；缺少依据时保持全范围占位，不用文风推断，也不展示虚构的「约 50%」。
4. 翻译、代码辅助、插图等参与环节与保留的 LLM 正文比例分别记录。只有代码或插图由模型生成，不足以估计正文比例。

### 阅读价值量尺的校准样本

以下六篇的相对顺序和分数间距已经校准。判断对象是本站实际提供的版本；对转载和翻译同时考虑原作内容与本站整理质量。

| 文章 | 暂定位置 | 判断依据 |
| --- | ---: | --- |
| 0001《楔子》 | 22 | 个人开篇记录与一条正则示例，保留个人档案意义，供站内技术读者复用的内容有限。 |
| 0196《命令行的艺术》 | 68 | 覆盖面广，命令行实用技巧密集；本站基本照录已有中文版，部分工具和平台语境随时间老化。 |
| 0188《用 DDIA 重读软件工程中的经典设计与权衡》 | 82 | 将成本、状态、故障与演进整合成可复用的架构评审问题；主要是已有知识的系统化综合。 |
| 0198《Consistency Models｜一致性模型》 | 86 | Jepsen 的模型关系图和基础定义具有长期参考价值，本站完整中英对照并保留地图；更深入的模型解释仍在外部专页。 |
| 0197《Deployment + PVC 能替代 StatefulSet 吗？》 | 88 | 区分存储、成员身份与数据库运维，引用固定版本源码并给出可操作的替换实验与故障边界。 |
| 0100《Conflict-free Replicated Data Types》 | 92 | 形式化 CRDT 论文的完整中英对照和大量译注，对分布式系统读者具有较高的长期研究与查证价值。 |
