# TeX Gyre Schola webfonts

The regular and italic WOFF files are the TeX Gyre Schola files served by
[Jepsen](https://jepsen.io/css/base.css), downloaded on 2026-09-24 without
modification. TeX Gyre Schola is distributed under the GUST Font License;
see `GUST-FONT-LICENSE.txt` and the [CTAN package page](https://ctan.org/pkg/tex-gyre-schola).
Jepsen's CSS defines the face as `texgyreschola` but names
`texgyrescholaregular` on `body`; this site registers the downloaded files
under their actual family name so the intended face is used consistently.

The site uses Noto Serif SC for Chinese through Google Fonts. Noto Serif SC is
licensed under the SIL Open Font License.
